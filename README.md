# Davye Sipariş Yönetim Paneli

Toptan satış siparişlerini ve depo toplama sürecini gösteren, derleme adımı olmayan statik HTML arayüzü.

## Kurulum
Gerekli: Python 3 (yalnız standart kütüphane). Bağımlılık yok.

## Çalıştırma
```bash
python3 server.py
```
Ardından: http://localhost:8888/index.html
